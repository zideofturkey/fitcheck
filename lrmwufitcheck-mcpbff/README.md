# FitCheck - MCP-BFF Service

AI Chat Interface Backend for FitCheck.

## Overview

The MCP-BFF (Model Context Protocol - Backend for Frontend) service acts as a hub that connects to multiple MCP servers in the project and provides a unified interface for the frontend chat UI.

## Features

- **MCP Client Hub**: Connects to all project MCP servers (auth, business services)
- **Tool Discovery**: Aggregates tools from all connected services
- **Tool Routing**: Routes tool calls to appropriate services with context injection
- **Chat Processing**: Natural language processing for user requests
- **Conversation History**: Maintains chat history for context

## API Endpoints

### Chat

- `POST /api/chat` - Send a chat message
- `POST /api/chat/tool` - Directly call an MCP tool
- `GET /api/chat/history/:conversationId` - Get conversation history
- `DELETE /api/chat/history/:conversationId` - Clear conversation

### Tools

- `GET /api/tools` - List all available tools
- `GET /api/tools/service/:serviceName` - List tools for a service
- `POST /api/tools/call` - Call a specific tool
- `GET /api/tools/status` - Get MCP connection status
- `POST /api/tools/refresh` - Refresh tool registry

### Health

- `GET /api/health` - Basic health check
- `GET /api/health/detailed` - Detailed health with connection status

## Architecture

```
Frontend (Chat UI)
       │
       ▼
   MCP-BFF Service
       │
       ├── Auth Service MCP (/auth-api/mcp)
       ├── Business Service MCP (/service-api/mcp)
       └── ... other services
```

The MCP-BFF connects to each service's MCP server via SSE, discovers available tools, and routes user requests to the appropriate service.
