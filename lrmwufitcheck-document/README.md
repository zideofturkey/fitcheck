# FitCheck - Documentation Server

This is the documentation server for the **FitCheck** project, generated by Mindbricks Genesis.

## Overview

This server provides:

- Static HTML documentation pages
- Markdown file downloads
- Dark/Light theme support
- Responsive navigation sidebar

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn

### Installation

```bash
npm install
```

### Running the Server

```bash
npm start
```

The server will start at `http://localhost:3000`

### Environment Variables

| Variable        | Description          | Default                  |
| --------------- | -------------------- | ------------------------ |
| `PORT`          | Server port          | `3000`                   |
| `STATIC_FOLDER` | Path to static files | `./static`               |
| `DOC_TITLE`     | Documentation title  | `FitCheck Documentation` |

## Folder Structure

```
/
├── server.js           # Express static file server
├── static/
│   ├── docs/          # Static HTML documentation pages
│   ├── md/            # Markdown files for download
│   └── doc-config.json # Navigation configuration
├── Dockerfile         # Production container
├── Dockerfile.stage   # Staging container
└── .gitlab-ci.yml     # CI/CD configuration
```

## Docker Deployment

Build and run with Docker:

```bash
docker build -t fitcheck-document .
docker run -p 3000:3000 fitcheck-document
```

Or use docker-compose:

```bash
docker compose up -d
```

## Features

### Markdown Downloads

Users can download the original Markdown source of any documentation page by clicking the "MD" button in the header.

### Theme Support

The documentation supports both light and dark themes. Users can toggle between themes using the theme button in the header. The preference is stored in localStorage.

### Responsive Design

The documentation is fully responsive and works on desktop, tablet, and mobile devices.
