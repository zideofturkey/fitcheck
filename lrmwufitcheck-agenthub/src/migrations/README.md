# Migrations

This folder contains database and Elasticsearch migrations for the **agentHub** service.

## Structure

```
migrations/
├── pending-migration.js   ← Current migration (gitignored, deleted after execution)
├── archive/               ← Archive of migration files (committed by deployer)
│   ├── migration-staging-1.0.0-to-1.1.0-2026-01-15T10-30-00.js
│   └── migration-prod-1.0.0-to-1.1.0-2026-01-16T14-00-00.js
└── README.md
```

## How It Works

### At Deploy Time (Deployer - has git access)

1. Genesis generates migration code via `/migration/code` API
2. Deployer saves to `archive/migration-{env}-{from}-to-{to}-{timestamp}.js`
3. Deployer commits archive to git (preserves history)
4. Deployer saves to `pending-migration.js` (gitignored)
5. Build and deploy to server

### At Service Startup (Server - no git access)

1. Migration runner checks `SERVICE_VERSION` vs DB-stored version
2. If `pending-migration.js` exists and versions differ → run migration
3. After successful migration → delete `pending-migration.js`
4. Archive was already committed by deployer, history preserved in git

## Environment Variables

| Variable                    | Description                | Default           |
| --------------------------- | -------------------------- | ----------------- |
| `SERVICE_VERSION`           | Target service version     | from package.json |
| `PROJECT_NAME`              | Project name for isolation | required          |
| `SERVICE_NAME`              | Service name for isolation | required          |
| `EXIT_ON_MIGRATION_FAILURE` | Exit if migration fails    | `false`           |

## Schema Version Tracking

Versions are tracked in the `_schema_versions` table:

```sql
SELECT * FROM _schema_versions WHERE service_id = 'fitcheck_agentHub';
```

## Manual Commands

Skip a pending migration (use with caution):

```javascript
const { skipMigration } = require("./utils");
await skipMigration();
```

## Migration History

Migration history is stored in git (`archive/` folder), not on the server.
To view migration history:

```bash
git log --oneline -- src/migrations/archive/
ls src/migrations/archive/
```
