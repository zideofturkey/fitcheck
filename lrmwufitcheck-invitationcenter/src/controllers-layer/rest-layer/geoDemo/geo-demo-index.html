Geo Demo Index

Autogenerated demos for all data objects with GeoPoint fields. Each link opens a map-based tester for the 3 standard geo APIs.

For each pair <objectName>.<geoField> we expose: /circle /nearest /bbox under the route: POST <serviceBase>/geo/<objectName>/<geoField>/*
The demo pages are served at: GET <serviceBase>/geo/<objectName>/<geoField>/demo
No GeoPoint fields were detected in your data objects. Once you define a GeoPoint property, geo demo pages will be generated here.
Mounted at <serviceBase>/geo. Demo links are relative, so they work with base paths like /store-service/geo.
